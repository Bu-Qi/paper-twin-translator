文献双屏译读 · Paper Twin 桌面版 1.2.1

本版界面改为奶油色与薄荷绿、圆角卡片及读书小伙伴插画。
正文和 PDF 页面保留清晰排版，原有语言、接口和阅读记录配置继续使用。

一、打开程序

解压后，双击 PaperTwin.exe。
支持 Windows 10 / 11 的 64 位电脑。
需要已安装 Microsoft Edge 或 Google Chrome 140 及以上版本，建议先更新到最新版。
不需要安装浏览器插件，不需要安装 Python、Node.js 或 Bun。
本程序使用本机浏览器的独立应用窗口显示界面，不是内置浏览器内核的 Electron 程序。

二、智谱免费翻译

1. 在程序右上角点击「设置」。
2. 点击「打开智谱 API Keys 页面」，登录后创建「模型标准 API」类型的 Key。
   官方入口：https://bigmodel.cn/usercenter/proj-mgmt/apikeys
3. 把 Key 粘贴到设置中，点击「保存设置」，再点「测试接口」。

程序已经预填：
接口：https://open.bigmodel.cn/api/paas/v4/chat/completions
模型：glm-4-flash-250414
语言：简体中文
领域：化学与制药

这个模型的官方文档标注免费，不用单独领取免费额度。
免费政策、速率限制和账户开通条件以智谱控制台当前显示为准。
不需要购买 Coding Plan；该套餐的 Key 与模型标准 API Key 不通用。
不要把 Key 发给他人，直接填写到本机程序即可。

三、英文／俄文／帕拉维语（中古波斯语）

设置中已经增加「原文语言」。
英文、俄文文献可选自动识别，也可明确选择英文或俄文。
翻成中文时，译文语言选择「简体中文」。
帕拉维语文献请在原文语言中选择「帕拉维语（中古波斯语，试验性）」。
在出现的古典文献设置中，标注原文形式：拉丁转写／转录、原字形文字层或混合。
可选择「历史与古典文献（伊朗学）」领域；帕拉维语模式会使用专门的文献释读提示。

帕拉维语是中古波斯语，不是现代波斯语。现代波斯语选项已单独标注。
本版帕拉维语功能是试验性辅助释读，未验证智谱免费模型的实际准确率。
优先使用经校勘的拉丁转写／转录文本；保留原文供人工逐项对照。
模型被要求标注存疑词、保留缺文与校勘符号，无法可靠释读时保留原文并说明。
这些要求无法保证模型遵守，输出不应直接作为权威译文或学术定本。

译文语言也可选择帕拉维语试验选项，此时要求输出拉丁转写／转录。
程序不提供帕拉维原字形生成，也没有专用帕拉维 OCR。
书籍体 Pahlavi 的历史字体映射可能影响复制和文字提取，不能只凭画面正常就认定文本正确。
原字形扫描件需要使用适合对应文字的工具及人工校勘；普通现代波斯语 OCR 未必适用。
拉丁转写按从左往右显示；可识别的原字形文字按 Unicode 方向自动显示。

原有现代波斯语互译仍保留，译文按从右往左显示。
更改原文语言或表示形式会使用独立缓存，避免混用上一个语言模式的译文。

参考资料：
智谱模型文档：https://docs.bigmodel.cn/cn/guide/models/free/glm-4-flash-250414
Pahlavi 文字与编码：https://unicode.org/events/utw/2026/talks/rendering-the-unencoded/
转写规范：https://www.iranicaonline.org/style-guide/

四、阅读文献

点击「导入 PDF / TXT」选择文件，或者「粘贴文本」。
左栏显示 PDF 原页，右栏显示对应页面的文字译文。
「翻译本页」只翻译当前页；「翻译全文」逐页翻译整篇文献。
可点击「暂停」，再次翻译时会跳过已经保存的译文。
「独立译文窗口」可以拖到第二块屏幕，窗口间同步翻页和滚动。
滚动同步按当前页相对阅读进度计算，不保证逐行对齐。
「导出对照」下载 Markdown 文件，可用文本编辑器或 Word 打开编辑。

桌面版不直接提取浏览器当前标签页。网页文献可复制正文后粘贴到程序中。
PDF 原文保留图片、表格和化学结构式；译文区域不重新绘制结构式或复刻表格版面。
扫描版 PDF 需先用其他工具进行 OCR。
复杂双栏 PDF 或特殊字体可能出现文字提取顺序问题，可粘贴正确顺序的正文。
单个导入文件最大 100MB。

五、保存的数据在哪里

程序数据保存在：
%LOCALAPPDATA%\PaperTwin\BrowserData

使用专用浏览器配置，不读取日常浏览器标签页、账号或扩展。
文献与译文缓存在本机；Key 也保存在此目录内，不加密，不做跨设备同步。
翻译时，待翻译的文字、领域和术语表会发送到你配置的接口。
接口费用及数据政策由对应服务商规定。
不同语言、模型、领域和术语表使用各自的译文缓存。
移动 EXE 不影响数据。桌面版与之前的扩展版各自保存记录，不自动迁移。
「阅读记录」内可以重新打开旧文献或清空文献与译文。
设置中的「删除 Key」用于单独移除密钥。

六、关闭与再次打开

关闭所有阅读、设置和译文窗口即可。
所有窗口关闭后，本机阅读服务约两分钟内自动退出。
再次双击 EXE 会重新打开界面。
本机服务只监听 127.0.0.1:17643，不向局域网开放。
首次使用若已有其他程序占用此端口，程序会提示错误。
程序窗口打开但显示连接失败时，可关闭全部窗口，等待两分钟后重新双击 EXE。
